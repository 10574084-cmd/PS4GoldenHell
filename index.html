Antes de continuar

Este sitio no ejecuta un jailbreak ni instala GoldHEN. Es una página informativa para homebrew. No incluye juegos, copias no autorizadas ni archivos de exploits.

Comprueba la versión exacta en Ajustes → Sistema → Información del sistema. No actualices la consola solo para intentar obtener compatibilidad.
